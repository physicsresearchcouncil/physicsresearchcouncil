# Round 3 Handbook (Problems 8–14)

## Problem 8: Electrodynamics (Self-Inductance of a Coaxial Cable)
Coaxial cable: inner radius a, outer radius b, current I. Self-inductance per unit length (magnetic energy between conductors only):
$$L_{\text{ind}} = \frac{\mu_0}{2\pi}\ln\left(\frac{b}{a}\right)$$

## Problem 9: Electrodynamics (Force Between Two Moving Charges)
Two charges q move parallel with speed v, separation d:
$$\frac{F_M}{F_E} = \frac{v^2}{c^2}$$

## Problem 10: Electrodynamics (Drift Velocity)
$$I = n e A v_d$$

## Problem 11: Thermodynamics (Stirling Cycle with Perfect Regeneration)
$$\eta = 1 - \frac{T_C}{T_H}$$

## Problem 12: Thermodynamics (Entropy Change in Gas Mixing)
Two different ideal gases, n moles each, expand into 2V:
$$\Delta S_{\text{total}} = 2 n R \ln 2$$

## Problem 13: Thermodynamics (Two-State Partition Function)
$$Z = 1 + e^{-E/(kT)}, \quad U_{\text{total}} = \frac{N E}{e^{E/(kT)} + 1}$$

## Problem 14: Thermodynamics (Joule-Thomson Coefficient for Ideal Gas)
$$\mu_{JT} = 0$$
